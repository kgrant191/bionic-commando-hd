INSTALL
Load Bionic Commando (USA).nes in Mesen/MesenCE.
Choose Tools > HD Packs (NES) > Install HD Pack, select this ZIP,
confirm installation, enable HD packs in NES video settings, and reload.

For a manual install, extract all files from the ZIP together into
  HdPacks/Bionic Commando (USA)/
The directory name must match the ROM filename without .nes.
