# v1.0.0 replay regression

Tested Bionic Commando (USA) with the MesenCE 2.2.1 Linux core at the pack's native 4× scale. The approved visual baseline was v0.23.6. Each distinct supplied input movie ran to completion with the release pack and with the original ROM. Byte-identical movie copies share one entry. The scene comparison uses changes to the game's room and area bytes on absolute emulator frames.

The suite visits all 19 numbered areas across 36 distinct recordings. They contain 317,411 input frames and 249 room or area changes. All recordings followed the original scene sequence. The maximum scene-change timing difference was 0 frames. The visual review used sampled HD frames, room changes and focused consecutive-frame checks. After narrowing the Area 18 overlay and overhead palette rules, the affected scenes were rechecked with the final artwork.

At 1,070 additional checkpoints across 27 recordings, the equipped weapon and the sampled object IDs and coordinates also matched the original game.

## Targeted checks

- **Area 12 escape**. In `12-2.mmo`, frames 7,750–7,756 lost the guardian on v0.23.6. The release restores all 24 missing guardian sprites in each of those seven frames. Checked the countdown in motion and replayed the rest of the fight, rescue and ending.
- **Rocket launcher**. The side-view firing animation uses dedicated flight graphics. Overhead encounters use a scaled copy of the same orb. Compared rendered launcher frames across rooms and verified the overhead screenshot against the opaque pixels of the scaled atlas tile. The shared explosion and pickup graphics retain their independent mappings.
- **Area 7 to Area 18**. The old global rooftop-guard hook broke the input replay before it could leave Area 7. The release reaches Area 18 on input frame 13,675 and finishes the route in room `$11`. Checked both rooftop guard orientations and their dialogue in `machine-gun.mmo`.
- **Stage 5**. The full `5.mmo` recording ran through the previously reported walk-right crash.
- **Installer**. Verified each of the 173 ZIP entries against the tested pack. All referenced image and patch files are present. All tile atlas coordinates fit their source PNGs. A clean rebuild reproduced the installer byte for byte.
