BIONIC COMMANDO HD — v0.1.0
Opening screens and Area 1 test build

INSTALL
Load your Bionic Commando (USA).nes ROM in Mesen/MesenCE.
Choose Tools > HD Packs (NES) > Install HD Pack, select this ZIP,
confirm installation, enable HD packs in NES video settings, and reload.

Manual install: put hires.txt and all PNGs together in:
  HdPacks/Bionic Commando (USA)/
The directory name must exactly match your ROM's filename without .nes.

THIS PASS
New title, radio interface, fortress, underground machinery,
communication-room and final-room environment art.
4x graphics, 1024 x 896 before aspect-ratio correction.
Top and bottom overscan trim: eight NES pixels each, hiding the observed
scrolling garbage. This is a presentation treatment, not a ROM patch.

WORK IN PROGRESS
Characters, enemies, portraits, reactor, effects, map, equipment screens
and Area Clear figure still use a smoothed 4x baseline. Some architectural
variants remain a recolored baseline. Further redraws are planned.
Only the supplied opening and Area 1 recording was tested.
Later areas and unrecorded states are not validated.
